# 攒钱计划与生活自由度

无需构建或第三方依赖的静态网页。通过 `investlab.publish.site_builder.build_site` 复制到发布目录的 `savings-planner/`，首页同时生成卡片和导航入口。不要直接修改历史 `docs/` 快照。

本地预览：在仓库根目录运行 `python3 -m http.server 8765`，打开 `/savings-planner/`。测试：`node --test savings-planner/model.test.js`；站点集成测试：`.venv/bin/python -m pytest tests/publish`。

- 有效年化换算为月收益率，月末投入，分红再投资；整月首次达到目标，最多推算 100 年。
- 当前计划、增加投入和改变收益率三个独立情景。图表最多展示 40 年，超出纵轴上限截顶，逐年表保留数值。
- 金额为名义人民币，不计通胀、税费与波动。年提取比例独立于收益率，不代表保证安全。
- 覆盖率参考最新月末资产，无记录时使用计划初始资产。支出按话费、水电煤费、吃饭、住房、其他依次累加。
- 月度记录按月份唯一，支持编辑、删除、刷新保留。滚动预测从最新记录的次月继续；未记录月份不推断为零投入。
- 数据保存在 `localStorage` 的 `investlab.savings-planner.v1`；支持带版本的 JSON 备份。导入完整验证后再替换，无效导入不修改数据。损坏的原始本地数据不会被自动覆盖，可先导出原始数据。
- 预算、工资及默认资产均为示例；不发起网络请求，不把计划或记录上传到服务器。

浏览器人工验证：默认提前 17 个月；月度记录新增与刷新保留；JSON 导出及导入恢复；320、375、768、1280 像素整页无横向溢出。计算测试覆盖有效年化、零收益、负收益、零投入、起点达标、不可达、日期跨年及损坏备份。

## 投入 × 年化探索

对比区可直接设置基础年化与对比年化，4% / 6% / 8% 快捷按钮与主计划同步。新计划默认基础 6%、对比 8%，不会自动覆盖已有计划。

`exploration.js` 提供网格坐标验证与固定达标时间配色。网格的横轴是月投入、纵轴是年化，每格为达标年数；点击显示整月用时与达标月份。支持定制范围和步长，最多每轴 100 个点、总计 2,500 格。网格显示设置随 JSON 备份一起保存，旧版备份兼容。


网格配色使用固定达标时间分段：≤5、5–10、10–15、15–20、20–30、>30 年，依次为深蓝、青绿、浅绿、黄、橙、红；100 年内未达标用灰色斜纹。同一达标年数不因网格范围改变而换色。
